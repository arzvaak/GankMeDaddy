WELCOME ABOARD

Four inputs. One local connection.

GankMeDaddy listens to the match data Dota already exposes, compares your state with role-aware benchmarks, and speaks useful cues. Here’s everything you’ll provide:

STRATZ tokenFetches pro benchmarks. Stored with Windows protection.
Steam account IDLoads your recent matches for context.
Dota folderLets us place one small configuration file.
Launch optionEnables Dota’s official local telemetry feed.
Your live match data never leaves your PC through this app.The GSI listener accepts connections only on 127.0.0.1—your own computer.

STEP 2 · STRATZ

Connect professional match intelligence.

STRATZ supplies item timings, builds, win rates, and role-aware professional benchmarks. GankMeDaddy only needs a personal API token.

Open STRATZ token page
  1. Sign in to STRATZ with Steam.
  2. Open API → My Tokens and create a token.
  3. Paste it below. We protect it with Windows encryption.

If a token is already secured, leave this blank to keep it.

STEP 3 · YOUR GAME

Tell us which player and installation to use.

Your STRATZ account ID is the shorter numeric ID shown in a STRATZ player URL—not the 17-digit SteamID64. The Dota folder should contain game\dota.

Example STRATZ URLstratz.com/players/123456789
Where is Dota usually installed?C:\Program Files (x86)\Steam\steamapps\common\dota 2 beta

If you use another Steam library, choose that library’s steamapps\common\dota 2 beta folder.

STEP 4 · LOCAL TELEMETRY

Install the GSI connection file.

This creates one readable text file inside Dota’s configuration folder. It tells Dota to send live match state to this app on your own computer.

Health, mana and level Items, abilities and cooldowns K/D/A, last hits and game time No keyboard, microphone or screen capture
